# Portafolio Rolando Silva

Portafolio web estatico para presentar proyectos, CV, stack tecnico y contacto.

## Abrir localmente

Abre `index.html` directamente en el navegador.

## Contenido

- Proyectos: FindMe!, Peluches Store, Humanitos en Construcción, Dragones Maps, English Course y ElectroLab.
- Assets: capturas reales copiadas a `assets/`.
- CV descargable: `assets/Rolando-Silva-CV.pdf` y `assets/Rolando-Silva-CV.docx`.
- LinkedIn: https://www.linkedin.com/in/rolando-silva-vique-407b00129/
- Estilo: minimalista rojo y negro con animaciones ligeras y guiños tipo videojuego.
